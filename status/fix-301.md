# tw deploy and Vite plugin builds (#301)

## What changed

- `cmd/tw/viteredirect.go` (new): when `<app>/.wrangler/deploy/config.json`
  exists, `loadWrangler` uses the config its `configPath` points at, as
  wrangler deploy does, and adds one line:
  `using build/server/wrangler.json, the config `vite build` wrote
  (.wrangler/deploy/config.json), as wrangler deploy does`. Relative paths
  in that config (`main`, `base_dir`, `pages_build_output_dir`, `tsconfig`,
  `assets.directory`, `d1_databases[].migrations_dir`, container
  Dockerfile paths) are rebased onto the project dir, so the rest of `tw`
  (assets, D1 migrations, images, dev watcher) keeps using `a.Dir`.
  `tailworks.jsonc` still comes from the project dir. Errors: a pointer to a
  missing config, a malformed pointer, and `--env` with a redirect (the
  generated config is already one environment: fix is
  `CLOUDFLARE_ENV=<name> npm run build`). Auxiliary Workers get one
  "not deployed" line each. Applies to everything that calls `loadAppWith`
  (deploy, dev, policy, types, kv/r2/secret/d1 name lookup).
- `cmd/tw/nobundle.go` (new): `no_bundle: true` plus ESModule rules whose
  globs are only `**/*.js` / `**/*.mjs` (other rule types limited to Text,
  Data, CompiledWasm) is "prebuilt": the built-in path packs `main` and every
  rule-typed file under `base_dir` (default main's dir) as is, skipping
  unmatched files (`wrangler.json`, `.vite/manifest.json`) and `.map`;
  `find_additional_modules: false` ships main alone. `app.builder()` returns
  `prebuilt`; the build line says so; the `no_bundle` / `find_additional_modules`
  / `base_dir` / `preserve_file_names` warnings are dropped for it (`build`
  is still warned). Any other no_bundle config is unchanged.
- Small edits: `app.go` (`switch a.builder()`), `wranglerapp.go` (redirect
  hook, rebase call), `wranglercfg.go` (warning case).
- Fixture `e2e/wrangler/testdata/vite-app` (user config whose main imports
  `virtual:react-router/server-build` and whose assets dir is wrong, the
  pointer, `build/server` pre-built Worker + chunk, `build/client` asset) and
  `TestDevViteRedirect` in `make e2e-wrangler`.
- Docs: `docs/wrangler.md#vite`, `#no-bundle`, bundling table row;
  `docs/COMPAT.md` wrangler-config and wrangler-bundling rows. Fragment
  `changes/fix-301.md` (changes-check did not require one).
